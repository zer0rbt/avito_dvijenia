# Категории Авито: Личные вещи → Одежда, обувь, аксессуары

**Статус:** ⚠️ ЧЕРНОВИК — не сверено с ЛК
**Источник:** черновик по открытым источникам, не сверено с ЛК аккаунта

## Общие поля
- `Id` — обязательное — наш internal_id, уникален в рамках фида
- `Title` — обязательное
- `Description` — обязательное
- `Price` — обязательное
- `Category` — обязательное (значение: `Личные вещи`)
- `GoodsType` — обязательное — подкатегория, см. goods_types ниже
- `Address` — обязательное — адрес из GEO_ADDRESSES, core/models.py
- `Images` — обязательное — минимум 1 фото, тег зависит от версии формата (Image/ImageUrls)
- `AdStatus` — опциональное — используется при затирке для перевода в архив
- `DateBegin` — опциональное
- `DateEnd` — опциональное — план: возможный триггер архивации в затирке, требует пилотной проверки

## Типы товара
### Мужская одежда (`mens_outerwear`)
- `GoodsType` = `UNVERIFIED`
- `Size` — обязательное — сетка мужской одежды: XS,S,M,L,XL,XXL,...; сверить допустимые значения
- `Color` — опциональное
- `Brand` — опциональное
- `Condition` — обязательное (значение: `Новое`)

### Женская одежда (`womens_outerwear`)
- `GoodsType` = `UNVERIFIED`
- `Size` — обязательное — сетка женской одежды — сверить
- `Color` — опциональное
- `Brand` — опциональное
- `Condition` — обязательное (значение: `Новое`)

### Мужская обувь (`mens_shoes`)
- `GoodsType` = `UNVERIFIED`
- `Size` — обязательное — размер обуви в штихмассовой системе (сверить формат: 40, 41...)
- `Color` — опциональное
- `Brand` — опциональное
- `Condition` — обязательное (значение: `Новое`)

### Женская обувь (`womens_shoes`)
- `GoodsType` = `UNVERIFIED`
- `Size` — обязательное — сверить формат размеров
- `Color` — опциональное
- `Brand` — опциональное
- `Condition` — обязательное (значение: `Новое`)
