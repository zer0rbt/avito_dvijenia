## Интерпретация и открытые вопросы по этому прогону

**Баланс: `{"bonus": 0, "real": 0}`.** Заказчик называл аванс ~900 ₽. История
операций тоже пуста. Это либо (а) аванс ещё физически не занесён на этот
кошелёк (900 ₽ было "будет закинуто", а не текущий остаток), либо
(б) баланс/аванс для тарифа "за просмотры" учитывается на другом счёте,
не видном через `/core/v1/accounts/{id}/balance/`. **Не подгонял под
ожидание — нужно уточнить у заказчика перед первой боевой публикацией**,
т.к. budget.py (Э5) блокирует публикацию при недостатке баланса, а с
текущим прочтением он заблокирует всё сразу.

**Autoload 404 — формулировка `"This route is temporarily unavailable"`
нетипична для "неверный путь".** Обычный 404 на несуществующий роут
Авито отдаёт иначе (см. balance/self/chats выше, которые просто отвечают
200). Эта формулировка больше похожа на "маршрут выключен для аккаунта/
приложения", что согласуется с тем, что Автозагрузка ещё не подключена
в ЛК (заказчик подтвердил: не подключена). Но нельзя исключить и то, что
сам путь `/autoload/v1/...` устарел. **Перепроверить этот же probe сразу
после подключения Автозагрузки в ЛК** — если тогда ответ изменится на 200
или на "пустой список отчётов", путь подтверждён; если 404 с той же
формулировкой сохранится — путь неверный и нужно искать альтернативу.
